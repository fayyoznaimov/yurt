# Сборщик скидок → сайт-каталог

Программа собирает товары из магазинов: со скидкой из Турции и подборки с YOOX (например, футболки известных брендов за 50–70 €). Отбирает те, что подходят под ваши фильтры, пересчитывает цену в сумы с вашей маржой и обновляет сайт-каталог.

## Запуск

```bash
python run.py
```

Через несколько минут откройте `site/index.html`.

- Режим владельца: `site/index.html?admin=1`. В нём видны себестоимость, маржа и ссылка на товар в магазине, а также сводки по источникам и брендам.
- Пересчитать цены без захода на сайты (например, после смены маржи или фильтров): `python run.py --offline`.
- Обновить один источник: `python run.py --only trendyol`. Для YOOX: `python run.py --only yoox_import`.

В конце `run.py` печатает сводку. По каждому источнику видно, сколько товаров подошло из собранного. По брендам печатаются 25 самых крупных, остальные одной строкой «…ещё N брендов».

## Что настраивается в `config.json`

Ключи, которые начинаются с `_` (например `_help`), — пояснения, программа их не читает.

| Поле | Что это |
|---|---|
| `sources` | какие источники использовать: `pcardin_tr`, `cacharel_tr`, `trendyol`, `yoox_import` (YOOX через кнопку) |
| `filters.brands` | бренды; пусто — все. Пробелы и знаки не важны: `Dolce & Gabbana` = `Dolce&Gabbana` |
| `filters.types` | типы: `обувь`, `сумки`, `рубашки`, `футболки и поло`, `толстовки`, `свитеры и кардиганы`, `куртки и пальто`, `пиджаки и костюмы`, `брюки`, `джинсы`, `шорты`, `платья`, `юбки`, `нижнее бельё`, `аксессуары`; пусто — все |
| `filters.genders` | `men`, `women`; пусто — все |
| `filters.discount_min` | минимальная скидка, %. `0` — брать и товары без скидки |
| `filters.price_min` / `price_max` | цена в магазине, **в валюте магазина**: евро для YOOX, лиры для Турции. Пусто или `0` у `price_max` — без ограничения |
| `filters.price_uzs_min` / `price_uzs_max` | диапазон цены продажи в сумах |
| `filters.only_with_sizes` | показывать только товары с известными размерами |
| `source_filters` | свои фильтры для одного источника, поверх `filters` (см. ниже) |
| `pricing.margin_pct` | ваша маржа, % |
| `pricing.min_margin_uzs` | минимальная маржа в сумах с одной вещи |
| `pricing.fx_markup_pct` | на сколько % вы покупаете валюту дороже курса ЦБ |
| `pricing.cargo_uzs_per_item` | доставка одной вещи до Ташкента: `TR` из Турции, `IT` из Италии |
| `pricing.fx_manual` | ручной курс, например `{"TRY": 245}`; пусто — курс ЦБ (cbu.uz) |
| `crawl.max_pages` | сколько страниц распродажи смотреть в каждом разделе (для всех источников) |
| `source_opts.<источник>.max_pages` | то же для одного источника, важнее `crawl.max_pages`. Например, `pcardin_tr.max_pages: 10` |
| `source_opts.trendyol.brand_slugs` | адрес бренда на Trendyol: откройте бренд на trendyol.com и скопируйте конец ссылки, например `pierre-cardin-x-b122` |
| `source_opts.trendyol.pdp_limit` | у скольких товаров Trendyol уточнять размеры (каждый товар — отдельная страница) |
| `source_opts.yoox_import` | YOOX: поиски для кнопки, бренды, фото (см. раздел про YOOX) |
| `site.contact_url` | **ваша ссылка в Telegram**, на неё ведёт кнопка «Заказать» |

### Свои фильтры для источника: `source_filters`

У турецких распродаж нужна большая скидка, а с YOOX вы берёте вещи известных брендов в диапазоне цены, даже без скидки. Для этого в `source_filters` задаются фильтры одного источника. Они заменяют те же поля из `filters`, остальные поля берутся из `filters`.

```json
"filters": { "brands": ["Pierre Cardin", "Cacharel"], "discount_min": 40, "price_uzs_max": 5000000, "only_with_sizes": true },
"source_filters": {
  "yoox": { "brands": [], "discount_min": 0, "price_min": 0, "price_max": 1000, "price_uzs_max": 50000000 }
}
```

Здесь для YOOX: бренды любые (их уже выбрала кнопка на YOOX), скидка не нужна, цена на YOOX до 1000 €, цена продажи до 50 млн сум. Размеры обязательны, как в `filters`. Для Турции действуют `filters`: только Pierre Cardin и Cacharel со скидкой от 40%.

Ключ в `source_filters` — источник товара: `yoox` (это и `yoox_import`), `pcardin_tr`, `cacharel_tr`, `trendyol`.

### Как считается цена

Цена продажи = (цена × курс ЦБ × (1 + наценка на курс) + доставка). К этой сумме прибавляется маржа: процент или минимальная, что больше. Результат округляется вверх до `round_to_uzs`.

## Источники

| Источник | Статус |
|---|---|
| Pierre Cardin Турция (раздел Garage Sale) | работает, обычные запросы |
| Cacharel Турция (разделы Outlet и «Online'a Özel») | работает, только мужская одежда |
| Trendyol | работает; размеры уточняются только у первых `pdp_limit` товаров |
| YOOX (`yoox_import`) | работает **через кнопку-закладку** (см. ниже) |
| YOOX автоматически (`yoox`) | выключен: YOOX блокирует браузер, которым управляет программа, и без окна, и с окном. Защиту не обходим |

Если один источник сломается, программа напишет ошибку и продолжит работать с остальными.

## YOOX через кнопку «Сохранить YOOX»

YOOX не пускает программы, но открывается в вашем Chrome. Поэтому товары с YOOX собирает кнопка-закладка: она работает на открытой вами странице YOOX и сохраняет товары в файл `yoox_….json` в «Загрузки». Потом `run.py` берёт эти файлы.

### Один раз: сделать кнопку

1. Запустите `python make_button.py`. Он возьмёт ваши поиски и бренды из `config.json` и соберёт страницу `yoox-knopka.html`.
2. Откройте `yoox-knopka.html` в Chrome и перетащите синюю кнопку на панель закладок (панели не видно — `Ctrl+Shift+B`).

**Поменяли `searches` или `known_brands`?** Снова запустите `python make_button.py`, откройте `yoox-knopka.html`, удалите старую закладку и перетащите кнопку заново. Закладка помнит поиски, которые были в момент перетаскивания.

### Каждый раз: собрать товары

Откройте любую страницу каталога YOOX, например `yoox.com/it/uomo/shoponline/t-shirt_c`, нажмите закладку и выберите режим:

- **1 — все мои поиски.** Кнопка по очереди откроет каждый поиск из `searches`. В каждом она отметит ваши бренды, поставит цену и сортировку и пролистает все страницы. Это то же, что вы делали руками: категория, известные бренды, «сначала дешёвые», 50–70 €.
- **2 — только эта выдача.** Сначала сами поставьте фильтры на YOOX: бренды, цену, сортировку. Потом нажмите кнопку, и она сохранит все страницы этой выдачи.

Между страницами кнопка ждёт 3–6 секунд, чтобы не нагружать YOOX. Если в одном поиске случилась ошибка, кнопка бросает этот поиск и переходит к следующему. Если YOOX ответил «слишком часто» или «доступ запрещён» (HTTP 403, 429, 503), сбор останавливается целиком. Кнопка «Стоп» останавливает сбор после текущей страницы. В любом случае собранное сохраняется.

Кнопка проверяет, что YOOX действительно применил фильтр брендов. Если среди товаров меньше 80% нужных брендов, такая выдача пропускается, чтобы не сохранить всю категорию.

В итоге кнопка покажет, сколько товаров собрано в каждом поиске и каких брендов на YOOX не нашлось. Редких брендов (1–2 вещи в категории) может не быть: YOOX показывает только 350 самых частых.

Потом запустите `python run.py` (или `python run.py --only yoox_import`). Товары YOOX пройдут фильтры `filters` + `source_filters.yoox` и получат цену в сумах. В одном файле могут быть и женские, и мужские поиски: раздел определяется у каждой страницы. Если товар есть в нескольких файлах, берётся самый новый файл.

### Настройки `source_opts.yoox_import`

| Поле | Что это |
|---|---|
| `searches` | поиски для режима 1: `name` — название, `url` — адрес категории на YOOX, `brands` — `"known"` (все из `known_brands`), свой список `["Boss", "Hugo"]` или `"url"` (ссылка как есть). Если `brands` не указан: для страницы бренда (`…/tombolini_d`) или ссылки, где бренды уже отмечены, берётся `"url"`, иначе `"known"`. `price` — `[от, до]` в евро, `sort` — `"PriceAsc"` (сначала дешёвые), `"BestDeals"` (лучшие скидки), `"Latest"` (новинки) |
| `known_brands` | известные бренды для `brands: "known"`; так же они пишутся на сайте (`EA7`, а не `Ea7`) |
| `max_pages_per_search` | сколько страниц по 60 товаров брать в одном поиске (YOOX отдаёт не больше 200) |
| `max_total_pages` | сколько страниц кнопка открывает за одно нажатие, по умолчанию 80 |
| `folder` | где искать файлы `yoox_*.json`; пусто — «Загрузки». Путь пишите через `/`, например `"D:/Загрузки"` (обратную черту `\` в JSON нужно удваивать) |
| `max_age_days` | файлы старше этого числа дней не берутся (по умолчанию 3): цены и наличие на YOOX быстро меняются |
| `download_images` | скачивать ли фото в `site/img/yoox/` |
| `max_images` | сколько новых фото скачать за один запуск (главное фото товара; сначала товары с большей скидкой, потом дешёвые). Уже скачанные фото используются всегда и лимит не тратят. У остальных фото показываются по ссылке с yoox.com |

Пример поиска:

```json
{ "name": "Поло мужские, 50–80 €", "url": "https://www.yoox.com/it/uomo/shoponline/polo_c",
  "brands": "known", "price": [50, 80], "sort": "PriceAsc" }
```

## Сайт

- Товары без скидки показываются без значка скидки, со строкой «В Италии: 57 €». В фильтре «Скидка» по умолчанию «Любая», при сортировке «По скидке» такие товары идут в конце.
- Если брендов больше 15, список брендов свёрнут: видны самые крупные и выбранные, остальные — по ссылке «Ещё N брендов» или через поиск «Найти бренд». Enter в поиске выбирает бренд, если найден один.
- Товары показываются по 48, дальше — кнопка «Показать ещё». Каталог на 3000 товаров фильтруется без задержек.

## Что выкладывать на хостинг

Из папки `site/` выкладываются: `index.html`, `products.js`, `products.json`, `img/`.

**Не выкладывайте `products-admin.js`.** В нём ссылки на магазины, себестоимость и маржа, он нужен только вам для режима `?admin=1`.

## Установка

Для Pierre Cardin, Cacharel, Trendyol и YOOX через кнопку нужен только Python 3.12 и пакет `requests`.

Для автоматического YOOX (`yoox`) ставился Playwright. Из-за длинного пути к этой папке пакеты установлены в `C:\Users\Asus\.venvs\deals-libs`. Этот источник выключен, поэтому эту папку и браузеры Playwright (`%LOCALAPPDATA%\ms-playwright`) можно удалить.
